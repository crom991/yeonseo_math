# 제품·학습 설계

## 1. 목적

둘째 자녀가 장소에 상관없이 휴대전화로 하루 약 10분씩 기초 연산을 연습하도록 돕는다. 빠르기 경쟁보다 정확성, 작은 성공 경험, 꾸준함을 우선한다.

## 2. 1차 버전 학습 흐름

1. `연습 시작`을 누르면 두 자리 수끼리의 받아올림 없는 덧셈에서 시작한다.
2. 한 화면에는 문제 하나와 답 입력칸만 크게 표시한다.
3. 답을 제출하면 정답 여부와 올바른 답을 짧게 확인하고 다음 문제로 이동한다.
4. 같은 단계에서 4문제를 연속으로 맞히면 한 단계 올라간다.
5. 최근 3문제 중 2문제를 틀리면 한 단계 내려간다.
6. 10분이 지나거나 학습자가 직접 마치면 결과 화면으로 이동한다.

## 3. 난이도 단계

| 단계 | 문제 유형 | 학습 의도 |
|---:|---|---|
| 1 | 두 자리 수 + 한 자리 수, 받아올림 없음 | 자신감 회복 |
| 2 | 두 자리 수 + 두 자리 수, 받아올림 없음 | 시작 진단 |
| 3 | 두 자리 수 + 두 자리 수, 받아올림 있음 | 현재 핵심 목표 |
| 4 | 두 자리 수 − 두 자리 수, 받아내림 없음 | 뺄셈 확장 |
| 5 | 두 자리 수 − 두 자리 수, 받아내림 있음 | 뺄셈 심화 |
| 6 | 세 자리 수 + 두 자리 수, 받아올림 있음 | 다음 단계 준비 |

## 4. 결과 지표

- 푼 문제 수
- 맞힌 문제 수
- 정확도
- 실제 학습 시간
- 다음 학습 권장 단계
- 최근 오답 최대 5개

점수는 다른 사람과 비교하지 않고 본인의 오늘 학습을 확인하는 용도로만 쓴다.

## 5. 개인정보와 저장 정책

1차 버전은 로그인, 이름 입력, 서버 데이터베이스를 사용하지 않는다. 풀이 기록은 현재 브라우저 세션에서만 유지되며 새로고침·세션 종료 시 사라질 수 있다. 공개 Streamlit 앱에 개인정보나 아이의 이름을 넣지 않는다.

## 6. 부모가 추가로 결정하면 좋은 항목

1. **기록 보관 여부**: 주간 변화 추이를 보려면 추후 부모용 PIN과 최소한의 익명 기록 저장 방식을 별도로 설계한다.
2. **교과 범위**: 덧셈·뺄셈이 안정된 뒤 곱셈, 나눗셈, 소수, 분수를 어느 순서로 열지 정한다.
3. **힌트 방식**: 받아올림·받아내림을 세로셈 그림으로 보여 줄지 아이 반응을 보고 결정한다.
4. **난이도 기준**: 1~2주 사용 결과를 보고 4연속 정답/최근 3문제 중 2오답 규칙을 조정한다.
5. **정서적 반응**: 시간 표시가 압박이 되면 남은 시간을 숨기고 진행 막대만 표시하는 선택지를 둔다.
6. **부모 확인 화면**: 아이 화면과 분리해 최근 7일 학습 여부와 자주 틀린 유형만 보여 줄지 정한다.

## 7. 다음 개선 우선순위

실제 사용 1주 뒤에 다음 순서로 검토한다.

1. 문제 글자와 버튼 크기, 답 입력 편의
2. 10분 동안의 피로도와 적정 문제 수
3. 반복해서 틀리는 자릿값·받아올림 유형
4. 난이도 상승 속도
5. 장기 기록 또는 부모 화면의 필요성
