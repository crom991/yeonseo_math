# 제품·학습 설계

## 1. 목적

연서와 하은이 장소에 상관없이 휴대전화로 하루 약 10분씩 기초 연산을 연습하도록 돕는다. 속도 경쟁보다 정확성, 작은 성공 경험, 꾸준함을 우선한다.

## 2. 학습 흐름

1. 로그인 없이 `연서 / 하은` 중 오늘 학습할 아이를 선택한다.
2. 각 아이의 첫 사용은 `두 자리 수 + 두 자리 수, 받아올림 없음`에서 시작한다.
3. 한 화면에는 문제 하나와 답 입력칸만 크게 표시한다.
4. 답을 제출하면 정답 여부를 확인하고 다음 문제로 이동한다.
5. 같은 영역 안에서 4문제를 연속으로 맞히면 한 단계 올라간다.
6. 최근 3문제 중 2문제를 틀리면 한 단계 내려간다.
7. 10분이 지나거나 학습자가 직접 마치면 선택한 아이의 결과로 저장한다.
8. 학습자는 `쉬웠어요 / 딱 좋았어요 / 어려웠어요` 중 하나를 남긴다.
9. 결과 화면에서 새 연습을 시작하거나 아빠에게 아이 이름이 포함된 Telegram 결과를 보낸다.

## 3. 17단계 학습 범위

| 영역 | 단계 | 문제 유형 |
|---|---:|---|
| 덧셈 | 1~4 | 두 자리 수+한 자리 수, 두 자리 수끼리, 받아올림, 세 자리 수 확장 |
| 뺄셈 | 5~7 | 받아내림 없는 두 자리 수, 받아내림 있는 두 자리 수, 세 자리 수 확장 |
| 곱셈 | 8~10 | 한 자리 수끼리, 두 자리 수×한 자리 수, 세 자리 수×한 자리 수 |
| 나눗셈 | 11~13 | 구구단 범위, 두 자리 수÷한 자리 수, 세 자리 수÷한 자리 수(나머지 없음) |
| 소수 | 14~15 | 소수 한 자리 덧셈, 소수 한 자리 뺄셈 |
| 분수 | 16~17 | 분모가 같은 분수 덧셈·뺄셈, 분모가 다른 분수 덧셈 |

세로셈·받아올림 힌트는 현재 요구에 따라 제공하지 않는다.

## 4. 난이도와 영역 조절 원칙

### 자동 성장

- 한 영역의 최근 2회 학습이 각각 5문제 이상, 정확도 80% 이상이고 두 번 모두 `어려웠어요`가 아니면 다음 영역을 연다.
- 열린 영역 가운데 누적 학습 횟수가 가장 적은 영역을 우선 선택해 특정 영역만 계속하는 현상을 막는다.
- 세션 안에서는 현재 영역을 벗어나지 않고 한 단계씩만 조절한다.
- `쉬웠어요`는 정확도 70% 이상일 때 다음 권장 단계를 한 단계 높이고, `어려웠어요`는 한 단계 낮춘다.

### 부모 지정

- 부모 화면에서 자동 성장에 포함할 영역을 선택할 수 있다.
- `부모 지정` 모드를 선택하면 부모가 정한 영역·시작 단계가 자동 규칙보다 우선한다.
- 강제 지정은 다음 10분 학습부터 적용한다.

## 5. 결과와 부모 화면

세션마다 날짜, 영역, 시작·종료·권장 단계, 푼 문제 수, 정답 수, 정확도, 실제 시간, 아이 느낌, Telegram 전송 시각, 문제별 결과를 저장한다.

부모 화면은 다음을 제공한다.

- 날짜별 결과 표
- 학습한 날·총 학습 횟수·총 문제 수·전체 정확도
- 2회 이상 기록이 있을 때 정확도 추이
- 자동 성장/부모 지정 전환 및 영역·단계 설정
- 부모 PIN 확인과 로그아웃
- 연서·하은 부모 PIN을 분리하고, 인증된 PIN에 연결된 아이 기록·설정만 표시

## 6. 저장·개인정보 정책

- 고정 프로필 이름 `연서 / 하은` 외에 학교, 연락처, 계정 정보를 수집하지 않는다.
- 아이 화면에는 로그인 절차를 두지 않고, 접속할 때마다 학습자를 다시 선택한다.
- 기존 구분 없는 기록은 `연서` 기록으로 이어받는다.
- 개발 환경은 `data/private`의 JSON 파일을 사용하며 Git에서 제외한다.
- Streamlit Community Cloud 운영 환경은 재시작에도 기록이 남도록 Supabase 연결을 권장한다.
- Supabase 접근은 서버 측 `SUPABASE_SERVICE_ROLE_KEY`만 사용하고 데이터 표에는 RLS를 켠다.
- Telegram 및 저장소 비밀값은 Streamlit Secrets에만 두고 코드·Markdown·Git에는 값이 아닌 이름만 적는다.

## 7. 1주 사용 후 점검 항목

- 10분 동안 실제로 푸는 문제 수와 피로도
- 아이의 체감 난이도 분포와 정확도의 일치 여부
- 자동으로 다음 영역이 열리는 속도
- 자주 틀리는 문제 유형과 특정 영역 회피 여부
- 부모 강제 설정을 얼마나 자주 사용했는지
- Telegram 결과 문구 하단에 Cloudflare 연산 웹페이지 링크를 표시
