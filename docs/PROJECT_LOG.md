### 요청 배경

- 초등학교 5학년 학습자가 두 자리 수 덧셈도 아직 빠르고 편하게 풀지 못하는 상태
- 모바일로 언제든 하루 약 10분 연습할 수 있는 웹페이지 필요
- 한 화면에 한 문제, 답 제출 후 다음 문제 진행
- 종료 후 시간과 점수 확인
- 기존 GitHub 계정과 Streamlit Community Cloud 배포 방식 재사용
- 모든 진행 내용을 Markdown과 Notion에 기록

### 결정

- 첫 문제는 두 자리 수 + 두 자리 수의 받아올림 없는 덧셈으로 시작
- 최근 결과에 따라 6단계 안에서 한 단계씩만 조절
- 속도 순위나 실패 표현 없이 정확도와 완료 경험을 강조
- 개인정보 입력과 영구 저장은 1차 범위에서 제외
- 학습 시간은 기본 10분이며 중도 종료도 허용

### 구현

- 모바일 중심 단일 문제 화면
- 10분 타이머와 진행 막대
- 정답·오답 피드백 후 자동으로 다음 문제 생성
- 적응형 난이도 조절
- 결과 요약 및 최근 오답 확인
- 문제 생성, 단계 조절, 결과 계산 단위 테스트

### 검증 기록

- 문제 생성·난이도 조절·결과 계산 자동 테스트 9건 통과
- Python 문법 검사 통과
- Streamlit 자동 화면 검사에서 시작 버튼 클릭 후 숫자 입력과 문제 화면 전환 확인
- 390×844 모바일 화면에서 시작 → 정답 제출 → 오답 제출 → 중도 종료 → 결과 확인 흐름 검증
- 모바일 문제 화면에서 한 문제만 크게 표시되고, 제출 후 다음 문제와 피드백이 함께 표시됨을 확인
- GitHub 원격 저장소와 Streamlit 운영 배포 결과는 실제 완료 상태를 확인한 뒤 추가한다.
- GitHub 저장소 생성 화면은 확인했으나 현재 배포 브라우저에 로그인 세션이 없어 인증 대기 중
