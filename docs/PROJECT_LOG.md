- 최근 결과에 따라 6단계 안에서 한 단계씩만 조절
- 속도 순위나 실패 표현 없이 정확도와 완료 경험을 강조
- 개인정보 입력과 영구 저장은 1차 범위에서 제외
- 학습 시간은 기본 10분이며 중도 종료도 허용

### 구현

- 모바일 중심 단일 문제 화면
- 10분 타이머와 진행 막대

- 적응형 난이도 조절
- 결과 요약 및 최근 오답 확인

## 2026-10-04 · 부모 알림·학습 기록·확장 난이도 추가

### 사용자 결정 반영

- 남은 시간은 계속 표시한다.
- 세로셈·받아올림 힌트는 추가하지 않는다.
- 곱셈·나눗셈·소수·분수를 선택 가능하게 하고, 부모가 강제로 영역과 단계를 지정할 수 있게 한다.
- 10분 학습 종료 후 아이에게 `쉬웠어요 / 딱 좋았어요 / 어려웠어요`를 묻고 다음 권장 단계에 반영한다.
- 날짜별 결과를 보는 부모 전용 화면을 추가한다.
- `새로 10분 연습` 바로 아래에 기존 수신처로 보내는 Telegram 버튼을 둔다.

### 구현

- 덧셈 4단계, 뺄셈 3단계, 곱셈 3단계, 나눗셈 3단계, 소수 2단계, 분수 2단계의 총 17단계 문제 생성
- 한 영역의 최근 2회가 각각 5문제 이상·정확도 80% 이상·`어려웠어요` 아님일 때 다음 영역을 여는 자동 성장 규칙
- 열린 영역 중 학습 횟수가 적은 영역을 우선 배정하는 편중 방지
- 부모 지정 모드와 정확한 시작 단계 강제 설정
- 로컬 JSON 저장 및 Supabase REST 저장소 전환 구조
- 부모 PIN 로그인, 날짜별 표, 누적 지표, 2회 이상일 때 정확도 추이, 학습 설정 화면
- Telegram 메시지 생성·전송, 전송 시각 저장, 같은 결과 중복 전송 방지
